# Projet iPhone Pro - Présentation Web

## Description du Projet

Ce projet est une application web de présentation pour l'iPhone Pro, conçue avec une esthétique moderne et minimaliste, inspirée des pages produits des grandes marques technologiques. L'objectif est de mettre en valeur les caractéristiques clés de l'appareil, d'offrir une expérience utilisateur fluide et interactive, et de permettre la sélection de différentes options (couleur, stockage) avec une mise à jour dynamique du prix et de l'image.

## Fonctionnalités

*   **Design Réactif :** L'interface s'adapte élégamment à différentes tailles d'écran, des ordinateurs de bureau aux appareils mobiles.
*   **Navigation Fluide :** Une barre de navigation fixe avec des liens de défilement doux vers les sections pertinentes de la page.
*   **Présentation du Produit :** Une section dédiée à l'iPhone Pro avec une description détaillée et une image principale.
*   **Sélection d'Options :** Les utilisateurs peuvent choisir la couleur et la capacité de stockage de l'iPhone. L'image du produit et le prix sont mis à jour en temps réel en fonction des sélections.
*   **Mise en avant des Caractéristiques :** Une section dédiée aux caractéristiques techniques et aux avantages clés du téléphone, présentée sous forme de cartes informatives.
*   **Appel à l'Action :** Des boutons clairs pour inciter à l'achat ou à en savoir plus.
*   **Esthétique Moderne :** Utilisation d'une palette de couleurs sombres, de typographies épurées et d'animations subtiles pour une expérience visuelle premium.

## Technologies Utilisées

*   **HTML5 :** Structure sémantique de la page web.
*   **CSS3 :** Stylisation de l'interface, incluant Flexbox, Grid, variables CSS, transitions et media queries pour la réactivité.
*   **JavaScript (ES6+) :** Gestion des interactions utilisateur, mise à jour dynamique du contenu (image, prix) et défilement doux.

## Installation et Utilisation

Pour visualiser ce projet localement, suivez les étapes ci-dessous :

1.  **Cloner le dépôt :**
    ```bash
    git clone https://github.com/votre-utilisateur/iphone-pro-presentation.git
    ```
2.  **Naviguer vers le répertoire du projet :**
    ```bash
    cd iphone-pro-presentation
    ```
3.  **Ouvrir le fichier `index.html` :**
    Double-cliquez simplement sur `index.html` dans votre explorateur de fichiers, ou ouvrez-le avec votre navigateur web préféré.

Le projet ne nécessite aucune dépendance serveur ou installation complexe. Il s'agit d'une application web statique.

## Structure des Fichiers

```
iphone-pro-presentation/
├── index.html
├── style.css
├── script.js
├── placeholder-bleu.png
├── placeholder-argent.png
├── placeholder-noir.png
├── placeholder-or.png
└── README.md
```

*   `index.html`: Contient la structure HTML de la page.
*   `style.css`: Contient toutes les règles de style CSS.
*   `script.js`: Contient le code JavaScript pour les interactions dynamiques.
*   `placeholder-*.png`: Images de substitution pour les différentes couleurs de l'iPhone.
*   `README.md`: Ce fichier, fournissant des informations sur le projet.
